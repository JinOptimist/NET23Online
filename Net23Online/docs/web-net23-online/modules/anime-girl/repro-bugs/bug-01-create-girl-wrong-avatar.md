# Сценарий: после создания героини на главной отображается не та картинка

## Что заметил тестировщик

Новая героиня появляется в списке на `/AnimeGirl/Index`, но превью не совпадает с загруженным файлом — вместо него видна стандартная заглушка.

## Предварительные условия

- Приложение запущено локально.
- Есть учётная запись с правом создавать героинь (авторизованный пользователь).
- В каталоге аниме может быть пусто — это нормально.

## Шаги воспроизведения

1. Войти в систему под пользователем с доступом к созданию персонажей.
2. Открыть страницу создания героини: `/AnimeGirl/CreateGirl`.
3. Заполнить поле **Name** значением из **6 символов** (например, `Sakura`).
4. Повторить то же имя в поле подтверждения имени.
5. В поле **Description** указать любой текст, **отличный** от имени (например, `Главная героиня`).
6. В поле **Url** ввести произвольный адрес картинки, например `https://example.com/test.jpg`.
7. Поле выбора аниме (**AnimeId**) оставить на пункте «SelectAnime» / пустым.
8. В блоке загрузки файла выбрать любое изображение `.jpg` с диска.
9. Нажать кнопку сохранения.
10. Дождаться редиректа на `/AnimeGirl/Index`.
11. Найти только что созданную героиню в списке и сравнить превью с загруженным файлом.

## Ожидаемое поведение (со слов аналитика)

После загрузки файла на главной должна отображаться именно загруженная картинка.

## Фактическое поведение

У части записей в списке остаётся дефолтное изображение, хотя файл, кажется, был выбран при создании.

## Подсказки для расследования (могут вводить в заблуждение)

- Проверьте, не ломает ли превью **валидация `DoubleCheck`** — возможно, форма иногда отправляется без файла.
- Посмотрите **Network** в DevTools: не режет ли браузер `multipart/form-data` из‑за размера файла.
- Сравните поведение с созданием героини **без** заполненного поля Url — если там всё ок, проблема скорее в конфликте Url и файла на клиенте.
- Проверьте CSS на `/AnimeGirl/Index`: класс `.media-card` может подменять `background-image` поверх `img`.
- Убедитесь, что SignalR-хаб `AnimeHub` не рассылает старое состояние каталога после создания.

## Что зафиксировать в отчёте

- Точное имя героини и длина строки Name.
- Было ли заполнено поле Url.
- Был ли выбран аниме в выпадающем списке.
- Скриншот карточки на Index и имя файла, который загружали.
