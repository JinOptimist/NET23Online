# Сценарий: таблица героинь падает с ошибкой при сортировке

## Что заметил тестировщик

Страница `/AnimeGirl/TableData` работает при обычном открытии, но после клика по заголовку определённой колонки приложение возвращает ошибку сервера (500).

## Предварительные условия

- В базе есть хотя бы несколько героинь.
- Приложение запущено.

## Шаги воспроизведения

1. Открыть `/AnimeGirl/TableData`.
2. Убедиться, что таблица отображается без ошибок.
3. Кликнуть по заголовку колонки **Id** — страница должна перезагрузиться с сортировкой.
4. Вернуться на `/AnimeGirl/TableData` (без параметров в URL).
5. Кликнуть по заголовку колонки **Title** (Name).
6. Снова вернуться на чистый URL таблицы.
7. Кликнуть по заголовку колонки **Connected anime** (третья колонка — связанные тайтлы).
8. Обратить внимание на адресную строку после клика.
9. Дополнительно: выбрать в фильтре «равно», ввести `2` в поле значения, затем повторить клик по колонке **Connected anime**.

## Ожидаемое поведение (со слов аналитика)

Любой заголовок таблицы должен сортировать данные или хотя бы оставлять список без изменений.

## Фактическое поведение

После шага 7 (и особенно 9) сервер отвечает ошибкой; колонки Id / Title / Url при этом ведут себя нормально.

## Подсказки для расследования (могут вводить в заблуждение)

- Проблема «очевидно» в **sort.js** — проверьте, не формирует ли скрипт невалидный URL для третьей колонки.
- Поле `ConnectedAnimeTitles` есть только во **view model**, а не в сущности — значит, EF не может сортировать, и падает SQL Server.
- Попробуйте отключить фильтр `sortType` / `sortValue` — якобы падает только комбинация фильтра «равно» и строковых полей.
- Сравните с `/AnimeGirl/AnimeTableData` — там три колонки и всё работает, значит баг в разметке `TableData.cshtml`, а не в `BaseRepository`.
- Проверьте локализацию заголовка третьей колонки — возможно, в `.resx` битый символ ломает `data-sort-by`.

## Что зафиксировать в отчёте

- Полный URL после клика по каждой колонке.
- Текст/stack trace ошибки с страницы разработчика или логов.
- Срабатывает ли баг без фильтра (шаг 7) и с фильтром (шаг 9).
