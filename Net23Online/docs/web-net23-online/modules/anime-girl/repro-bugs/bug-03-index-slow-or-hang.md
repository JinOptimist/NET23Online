# Сценарий: главная Anime Girl долго грузится или «зависает»

## Что заметил тестировщик

Страница `/AnimeGirl/Index` иногда открывается десятки секунд, браузер показывает «ожидание ответа сервера». На маленькой базе всё быстро.

## Предварительные условия

- В таблице героинь **больше 10** записей (при необходимости создать через `/AnimeGirl/CreateGirl` или наполнить сидом).
- Есть доступ в интернет (страница тянет внешние API: шутки, waifu, коты).
- Желательно два браузера или две вкладки.

## Шаги воспроизведения

1. Убедиться, что в БД как минимум **11** героинь (посчитать на `/AnimeGirl/TableData` или в админке БД).
2. Открыть `/AnimeGirl/Index` в первой вкладке — засечь время до полной отрисовки.
3. Сразу открыть `/AnimeGirl/Index` во **второй** вкладке (или в другом браузере) — снова засечь время.
4. Повторить шаги 2–3 **три раза** подряд.
5. Для сравнения удалить или временно скрыть лишних героинь, чтобы осталось **не больше 10**, и снова открыть Index дважды параллельно.
6. В DevTools → Network отфильтровать запросы к `official-joke-api`, `waifu.im`, `cataas.com` и записать их длительность.

## Ожидаемое поведение (со слов аналитика)

Главная должна открываться за 1–3 секунды независимо от числа карточек в каталоге.

## Фактическое поведение

При большом каталоге и параллельных заходах страница отвечает заметно дольше; иногда кажется, что сервер «встал».

## Подсказки для расследования (могут вводить в заблуждение)

- Начните с **медленных внешних API** — если joke-api тормозит, виноват только `HttpClient` timeout.
- Проверьте **SignalR** подключение на Index: чат может блокировать рендер основного потока.
- Посмотрите N+1 в `GetAllIncludeAnime` — якобы при 11+ героинях EF делает лавину запросов.
- Сравните с `/AnimeGirl/TableData` — там нет внешних API, значит проблема «точно не в репозитории».
- Проверьте query-параметры `?count=1|2|3` в шапке Index — возможно, сервер режет выборку и из‑за этого всё ломается.

## Что зафиксировать в отчёте

- Число героинь в БД.
- Время ответа Index при ≤10 и при >10 записях.
- Были ли параллельные вкладки.
- Длительность внешних HTTP-запросов из Network.
